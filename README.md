# Netflix Movies & TV Shows Analysis Dashboard

An interactive Power BI dashboard analyzing Netflix's global library of 8,000+ titles, highlighting content distributions, release trends over time, ratings, and country-level distributions.

---

## 📊 Dashboard Preview

![Netflix Dashboard Preview](dashboard_preview.png)

---

## 🔑 Key Insights & Features

* **Content Breakdown:** Visualizes the proportion of Movies vs. TV Shows across the entire library.
* **Release Trends:** Tracks content growth over time from 2000 to 2021.
* **Audience Ratings:** Categorizes titles by content rating (TV-MA, TV-14, PG-13, etc.).
* **Geographical Distribution:** Interactive map showing content production by country.
* **KPI Metrics:** Quick-glance cards for Total Titles, Total Genres, and Total Directors.

---

## 🛠️ Tools Used

* **Power BI Desktop:** Data modeling, DAX calculations, and interactive visualizations.
* **Dataset:** Netflix Titles CSV dataset.

---

## 🚀 How to View the Dashboard

1. Download the `Netflix Data Analysis Dashboard.pbix` file from this repository.
2. Open the file in **Power BI Desktop**.
